# Mixtape — เครื่องเล่นเพลงส่วนตัว

แอปเล่นเพลงที่ใช้ไฟล์เพลงที่คุณดาวน์โหลดมาเก็บไว้ในเครื่อง เก็บเพลงด้วย IndexedDB
(พื้นที่เก็บข้อมูลในเบราว์เซอร์) เพลงจะอยู่ในเครื่องถาวร ไม่หายแม้ปิดแอปหรือปิดเน็ต

ไฟล์ในนี้:
- `index.html` — ตัวแอปทั้งหมด (UI + โค้ด)
- `manifest.json` — ทำให้ติดตั้งเป็น "แอป" บนมือถือได้ (PWA)
- `sw.js` — service worker ให้เปิดแอปได้แม้ไม่มีเน็ต
- `icon-192.png`, `icon-512.png` — ไอคอนแอป

## วิธีใช้แบบฟรี 100% — โฮสต์ด้วย GitHub Pages

ต้องโฮสต์เป็นเว็บ (ไม่ใช่เปิดไฟล์ตรงๆ) เพราะ service worker และการ "ติดตั้งเป็นแอป"
ต้องใช้ HTTPS เท่านั้น GitHub Pages ให้ฟรีและไม่ต้องผูกบัตรเครดิต

1. สร้างบัญชี GitHub ฟรีที่ github.com (ถ้ายังไม่มี)
2. สร้าง repository ใหม่ ตั้งชื่อเช่น `mixtape-player` เลือก **Public**
3. อัปโหลดไฟล์ทั้ง 5 ไฟล์นี้เข้าไปใน repo (ลากไฟล์ลงหน้าเว็บ GitHub ได้เลย ไม่ต้องใช้ terminal)
4. ไปที่ **Settings → Pages**
5. ที่ "Branch" เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอ 1-2 นาที จะได้ลิงก์ประมาณ
   `https://ชื่อบัญชีคุณ.github.io/mixtape-player/`
7. เปิดลิงก์นี้บนมือถือด้วย Chrome หรือ Safari

## วิธีติดตั้งเป็นแอปบนมือถือ

**Android (Chrome):** เปิดลิงก์ → แตะเมนู 3 จุด → "เพิ่มลงหน้าจอโฮม" หรือ "ติดตั้งแอป"

**iPhone (Safari):** เปิดลิงก์ → แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) → "เพิ่มไปยังหน้าจอโฮม"

จากนั้นจะมีไอคอนแอปคาสเซ็ตต์บนหน้าจอโฮม เปิดแล้วเต็มจอเหมือนแอปจริง ไม่มีแถบ URL

## วิธีเพิ่มเพลง

เปิดแอป → กด "เพิ่มเพลงจากเครื่อง" → เลือกไฟล์เพลง (mp3, m4a, wav ฯลฯ) ที่ดาวน์โหลดไว้ในมือถือ
เลือกได้หลายไฟล์พร้อมกัน เพลงจะถูกบันทึกไว้ในตัวเครื่อง เปิดแอปครั้งหน้าเพลงยังอยู่ครบ

## ข้อควรรู้

- เพลงถูกเก็บ **ในเครื่อง/เบราว์เซอร์เท่านั้น** ไม่ได้อัปโหลดขึ้นที่ไหน ไม่มีใครเห็นเพลงคุณ
- ถ้าล้างข้อมูลเบราว์เซอร์ (clear browsing data) เพลงที่เพิ่มไว้จะหายไปด้วย
- ทุกอย่างฟรี ไม่มีค่าใช้จ่ายใดๆ ทั้ง GitHub Pages และตัวแอป
- อยากทดสอบก่อนโฮสต์จริง ก็เปิด `index.html` ตรงๆ ในเบราว์เซอร์บนคอมได้ (ฟีเจอร์หลักใช้ได้
  ยกเว้นการติดตั้งเป็นแอปที่ต้องมี HTTPS)

## ปรับแต่งเพิ่มเติม (ถ้าเขียนโค้ดเป็น)

โค้ดทั้งหมดอยู่ใน `index.html` ไฟล์เดียว (CSS + JS ฝังในนั้น) แก้สีธีมได้ที่ตัวแปร CSS
ด้านบนของไฟล์ (`--bg`, `--amber`, `--teal` ฯลฯ) หรือจะเพิ่มฟีเจอร์ เช่น สุ่มเพลง (shuffle),
เล่นวน (repeat), จัดกลุ่มเป็นเพลย์ลิสต์ย่อย ก็ต่อยอดจากโครงสร้างนี้ได้เลย
